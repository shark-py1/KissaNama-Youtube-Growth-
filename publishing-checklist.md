# Publishing & SEO Checklist

- [ ] Title is specific, intriguing, and accurate
- [ ] First 1–2 lines of description explain the story
- [ ] Description includes relevant context and credits where needed
- [ ] Thumbnail is readable on a phone and matches the story
- [ ] Playlist selected
- [ ] Audience setting is correct
- [ ] Language and captions reviewed
- [ ] End screen / cards added where appropriate
- [ ] Pinned comment encourages a genuine discussion
- [ ] No misleading tags, metadata, or thumbnail claims
